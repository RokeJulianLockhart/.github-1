# `.github`

This repository acts as the source of truth for all other repositories under this organisation.

Although issues with this specific repository's content are to be submitted at `/issues`, generic feature requests are to be submitted at [`protonmail.uservoice.com`][1], whereas generic support requests are to be submitted at [`proton.me/support/contact`][2].

[1]: https://protonmail.uservoice.com/

[2]: https://proton.me/support/contact
